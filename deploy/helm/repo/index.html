NGX Storage NFS CSI Driver

Helm chart repository for the NGX Storage NFS CSI driver (provisions NFS shares from NGX Storage Manager).

Add the repository

helm repo add ngx-nfs-csi https://ngxstorage.github.io/nfs-csi-ngxstorage-driver
helm repo update

Install

helm install ngx-nfs-csi ngx-nfs-csi/nfs-csi-ngxstorage \
  --namespace nfs-csi-ngxstorage --create-namespace \
  --set openshift.enabled=true \
  --set secret.create=true \
  --set secret.storageIPs='192.168.1.201,192.168.1.202' \
  --set secret.poolName='openstackSSD1' \
  --set secret.apiKey='<api-key>' \
  --set secret.dataIP='10.10.10.202'
